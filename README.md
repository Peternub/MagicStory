# MagicStory

Сервис персональных детских сериалов на Next.js.

## Инфраструктура

- приложение и PostgreSQL работают на VPS в Москве;
- PostgreSQL доступна только локально через `127.0.0.1`;
- авторизация работает по email и паролю через Better Auth;
- пароли хранятся как Argon2id-хеши;
- изображения и озвучка в текущей версии не используются;
- внешний AI-провайдер получает только обезличенный контекст сказки.

## Локальный запуск

1. Создайте `.env.local` на основе `.env.local.example`.
2. Установите зависимости: `bun install`.
3. Запустите проект: `bun run dev`.

До подключения HTTPS держите `AUTH_ENABLED=false`.

## Проверки

- `bun test`
- `bun run typecheck`
- `bun run build`

## PostgreSQL

Миграции находятся в каталоге `postgres/migrations`. Порт `5432` наружу не публикуется.
